------------------------------------------------------------------------------
LANGKAH MUDAH MENGAKTIFKANNYA (HANYA 2 MENIT - 1 KALI SEUMUR HIDUP):
------------------------------------------------------------------------------

Langkah 1: Buat Repositori GitHub Gratis
1. Buka website https://github.com (daftar gratis jika belum punya akun).
2. Klik tombol "New" (Buat Repositori Baru).
3. Beri nama repositori, misalnya: `donghua-database`
4. Pilih "Public" dan klik "Create repository".

Langkah 2: Upload File-File Ini ke GitHub Anda
1. Di repositori GitHub baru Anda, klik "Add file" -> "Upload files".
2. Upload file `updater.py` dan `donghua_catalog.json`.
3. Buat folder bernama `.github/workflows/` dan masukkan file `auto_update_workflow.yml`
   (atau ganti namanya menjadi `auto_update.yml`).
4. Klik "Commit changes".

Langkah 3: Selesai! Bot Akan Bekerja Sendiri!
- GitHub Actions akan otomatis menjalankan `updater.py` setiap beberapa jam.
- Jika ada episode baru dari rilis donghua di internet, file `donghua_catalog.json` akan otomatis bertambah.
- Aplikasi Android Anda akan otomatis menyedot episode terbaru tersebut setiap kali dibuka oleh penonton.
